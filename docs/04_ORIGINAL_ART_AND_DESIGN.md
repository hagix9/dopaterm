## 1. アートディレクションの核 (Art Concept)

### 「Terminal meets Arcade & Dopamine Pop」
従来のCLIツールが持つ「冷淡でストイックな黒画面」「無機質な緑やシアンのテキスト」という固定観念を覆し、**「80s〜90sアーケードゲームの過剰な演出感」と「2020年代の洗練されたポップ・パステルUI」を融合**させます。

- **禁止事項**:
  - Dopa Drillの「ドパキチ」や特定キャラクターのシルエット・名称・意匠の流用。
  - 単なる黒背景＋毒々しいネオンだけの「使い古されたサイバーパンク」。
  - ターミナルの文字視認性（コントラスト比）を著しく損なう背景ノイズ。
- **推奨事項**:
  - **コントラストの確保**: ターミナル文字表示領域はダークパープル/ディープネイビー（`#13111C`）を基調とし、文字の可読性（WCAG AAA水準）を最優先。
  - **過剰なポップアクセント**: 演出部分にはエレクトリックピンク、ミントグリーン、レモンイエロー、サイバーシアンなどの高彩度キャンディカラーを惜しみなく投入。
  - **弾むモーション (Juiciness)**: スプリング物理（ばね・減衰）による有機的なバウンス感。

## 2. オリジナルマスコットのデザイン候補 (3案)

Dopa Drill（恐竜・怪獣系）とは明確に異なる、Dopaterm独自のキャラクターデザインを3案提示します。

│     /\_/\   [= O.O =]     │       __  (• ө •)         │        /\   / \           │

│    > ^ <    \________/    │    |  🐧  | [ブースター]   │      <  💎 ✨ 💎 >        │
│                           │     \____/                    │       \  / \   /          │

### 案A: 「ターミにゃん / Termi-Nyan」（本命・推奨案）

- **モチーフ**: 電脳サイバー猫 × レトロ宇宙飛行士
- **カラーリング**:
  - ボディ: ミルキーホワイト (`#F8F9FA`)
  - ヘルメットバイザー: エレクトリックシアン (`#00F0FF`) & ネオンピンク (`#FF007F`) のグラデーション
  - 耳/しっぽ先端: 発光ミント (`#00FFA3`)
- **シルエットとパーツ構成 (SVGレイヤー)**:
  1. `body`: 丸みを帯びたしずく型胴体
  2. `head`: バイザー付きヘルメット
  3. `ears`: 左右の三角耳（左右独立してピクピク動く）
  4. `eyes`: LEDバイザー内のドットマトリクス目（通常: `^ ^`、コピー中: `> <`、成功時: `★ ★`、エラー時: `@ @`）
  5. `mouth`: カプセル発射口
  6. `tail`: アンテナ付きしっぽ（サイン波でゆらゆら揺れる）
  7. `hands`: 浮遊するポッド状の手
- **アニメーション挙動**:
  - **待機 (Idle)**: ヘルメットが上下にふわふわ浮遊（Spring周波数: 1.5Hz）。
  - **候補検知 (Candidate)**: 耳がピンと立ち、バイザーに「READY?」の文字がスクロール。
  - **コピー実行中 (Started)**: 口から「📄 カプセル」を次々と発射し、両手で空中にトス。
  - **成功 (Finished 0)**: 両手を突き上げて大ジャンプ、バイザーが虹色に点滅し「PERFECT!」プラカードを掲げる。
  - **失敗 (Finished 1+)**: ヘルメットから小さな煙が出て、しょんぼりと耳を垂らす。

## 3. コンボ段階別の画面構成と演出仕様

```text
コンボの進化ツリー:
[1〜9回: NORMAL?] ──▶ [10〜99回: COMBO!] ──▶ [100〜999回: FEVER!!]
                                                    │
                                                    ▼
[10,000回以上: DOPA SINGULARITY] ◀── [1,000〜9,999回: HYPER DOPA]
```

### 3.1 各ランクの画面構成詳細
1. **NORMAL? (1〜9回)**:
   - 画面上部: 控えめなポップアップバッジ `COMBO xN`。
   - ファイル飛行: 1個ずつ弧を描いてコピー先へ飛翔。
   - マスコット: パチパチと控えめな拍手モーション。
2. **COMBO! (10〜99回)**:
   - 画面四隅: 金貨（Gold Coins）と紙吹雪が噴出。
   - 中央バナー: 「🔥 COPY COMBO x10 🔥」ネオンカードがバウンス表示。
   - マスコット: 空中で1回転宙返り。
3. **FEVER!! (100〜999回)**:
   - 背景: WebGLによるサイバーネオン・レインボートンネル（放射状の光線が奥へ疾走）。
   - 画面端: 左右からピンクとシアンのレーザービームが交差。
   - パーティクル: ファイルが5〜10個の束で超高速シャワーのように飛翔。花火が連続爆発。
4. **HYPER DOPA (1,000〜9,999回)**:
   - 背景: ディープスペース（星屑ワープ、巨大な星雲）。
   - マスコット: 画面背景に半透明の巨大マスコット（画面の半分を覆う）が乱入し、サムズアップ。
   - 電光掲示板: 「HYPER DOPA MODE ENGAGED」「COPY GOD IN PROGRESS」がマーキー走行。
5. **DOPA SINGULARITY (10,000回以上)**:
   - 空間特異点: 一瞬画面全体がホワイトフラッシュ（閃光）。
   - 巨大メッセージ: ネオン管で **「WHY ARE YOU STILL COPYING?」**（なぜまだコピーしているのか？）がゆっくり3D回転。
   - エンドロール: 画面右端に映画のような縦スクロールクレジット（総コピー回数、連続記録、仮想スタッフロール）が流れる。

## 4. 失敗演出・DISASTER MODE のビジュアル仕様

### 4.1 失敗・タイプミス演出
- **TYPO!! 激突**:
  - レトロゲーム風の極太フォントで描かれた「💥 TYPO!! 💥」の巨大ボクセルブロックが画面最上部から重力落下（`gravity = 1.2`）。
  - 激突時に画面全体が2フレームだけ強く縦揺れ（Shake）、ブロックから破片パーティクルが飛び散る。
- **南京錠 (Permission denied)**:
  - 巨大な鋼鉄製南京錠のSVG。上から「ガシャーン！」と落下し、鍵穴から青白い火花が散る。
- **墓石と幽霊 (File not found)**:
  - ドット絵調の「R.I.P」墓石が下からせり上がり、半透明の可愛い幽霊が「ヒュー…」と浮かんで消える。
- **火山噴火 (Build failed)**:
  - 画面下部から溶岩の火山が出現、マグマの火の粉パーティクルが画面いっぱいに広がる。

### 4.2 DISASTER MODE（災害・破滅演出）
- **ファイル爆発 (`rm`)**: ファイルアイコンが赤く点滅した後、「💣 ドカン！」とコミカルに破裂。
- **大量削除 (`rm -rf`)**: 地平線に描かれたビル群シルエットがガラガラと崩壊し、上空から燃え盛る巨大隕石が尾を引いて落下。
- **ディスク容量不足 (No space left)**: 画面下からネオンブルーの水位（波のシェーダー）が上昇し、ターミナル文字が水中で揺らぐ（泡パーティクル）。
- **OOM (Out Of Memory)**: 画面外から巨大怪獣の口がガバッと現れ、暴走プロセスのアイコンを「バクッ！」と一呑み。
- **GAME OVER (コンテナ・プロセス停止)**: 画面全体がレトロアーケードの「GAME OVER」画面に暗転（0.8秒で復帰）。

## 5. 音響デザイン仕様 (Web Audio API Synthesizer)

音声ファイル（mp3/wav）を一切使用せず、オシレーターで全効果音をリアルタイム合成します。

| イベント | 音色名 | 合成パラメータ |
|---|---|---|
| **キーストローク (Candidate)** | `Blip` | Sine 800Hz → 1200Hz (20ms, gain: 0.1) |
| **コピー開始 (Started)** | `Transfer Whistle` | Triangle 300Hz → 900Hz スイープ (150ms) |
| **成功 (NORMAL)** | `Chime Duo` | Sine C5 (523Hz) + E5 (659Hz) (200ms) |
| **成功 (COMBO)** | `Arpeggio` | Sine C5 → E5 → G5 → C6 高速分散和音 (300ms) |
| **成功 (FEVER)** | `Fanfare Synth` | Sawtooth + Lowpassフィルター ブラス風3和音 (500ms) |
| **特異点 (SINGULARITY)** | `Symphonic Chord` | 壮大な長調メジャーセブンス和音 + 電子グロッケン (1.5s) |
| **TYPO 激突** | `Heavy Crash` | ホワイトノイズバースト + 80Hz重低音サイン波 (250ms) |
| **南京錠** | `Metal Lock` | Square 1200Hz + 金属反響ディレイ (180ms) |
| **ファイル不在** | `Ghost Spooky` | Sine ピッチダウン 600Hz → 200Hz ビブラート (400ms) |
| **DISASTER 爆発** | `Explosion Noise` | Lowpassノイズ + サブベース 50Hz (600ms) |
| **DISASTER GAME OVER** | `Chiptune Mourn` | レトロ8bit風 下降アルペジオ (400ms) |
